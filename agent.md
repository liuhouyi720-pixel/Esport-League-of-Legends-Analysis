# Project language rules

- Reply to the user in English by default, including when the user's prompt is in Chinese.
- Reply in Chinese only when the user explicitly requests a Chinese response in the current prompt.
- Always write code comments, annotations, and docstrings in English.
- Always write notebook Markdown in English, including headings, explanations, interpretations, and notes.
- Keep code annotations and notebook Markdown in English even when the user explicitly requests a Chinese conversational response.
- Apply these project language rules instead of any skill's default preference for Chinese replies, code annotations, or notebook Markdown.
